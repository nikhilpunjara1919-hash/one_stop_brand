# One Stop Brand Store — Phase 1

Customer-facing React + Vite + Motion website.

## Run locally
Install Node.js LTS, then from this folder:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production
```bash
npm run build
```
The deployable files are in `dist/`.

## Included
- Premium + modern responsive design
- Home, Collections, About, Instagram, Visit Us
- Category tabs
- Product detail modal
- Smooth Motion animations
- Phone enquiry
- Google Maps directions
- Instagram link
- No prices
- No WhatsApp
- No admin panel yet (planned for Phase 3)
